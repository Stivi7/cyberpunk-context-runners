# Memory Curation

## Metadata

- Version: 1.0.0
- Triggers: Retrospective, repeated failure, validated convention, or durable decision
- Allowed agents: Nexus, Operator, Gatekeeper
- Side effects: Updates tracked project memory

## When to Use

Use after evidence exists. Keep raw attempts in local run state and do not promote ordinary narration.

## Inputs

Task evidence, review result, existing decisions, patterns, lessons, project scope, and candidate entry.

## Procedure

1. Classify the candidate as a decision, proven pattern, lesson, or temporary observation.
2. Reject content that is unsupported, one-off, non-actionable, duplicative, machine-specific, or contains a secret.
3. Require a lesson to be evidence-backed, generalizable, and actionable.
4. Merge with an existing entry when possible.
5. Record scope, evidence, status, and revisit conditions.
6. Mark contradicted or obsolete entries superseded rather than silently deleting history.

## Verification

Gatekeeper confirms evidence, applicability, lack of secrets, and absence of contradiction before promotion.

## Output

Promoted, updated, rejected, or superseded entry with rationale and evidence reference.
